# Ateliê Vesper

Modelo de site para estética e harmonização facial. Marca, nomes, avaliações e endereço são fictícios (modelo de demonstração).

Ao vivo: https://alissonlittig.github.io/atelie-vesper/

- HTML, CSS e JavaScript puros, sem build e sem rastreador. Fontes WOFF2 locais.
- Mobile primeiro, agenda pelo WhatsApp (link de exemplo), avaliações, serviços, mapa estilizado e SEO local básico (title, description, canonical, Open Graph e JSON-LD).
- Detalhe de design: o arco como forma-assinatura e índice de tratamentos.

Para usar com um cliente real: trocar nome, endereço, link do WhatsApp, avaliações do Google, fotos e dados profissionais.
